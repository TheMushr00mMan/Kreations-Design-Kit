# Clip library (v01–v22 videos, n01–n12 live sites and footers, s01–s12 slide decks)

The evidence behind the skill. One entry per reference concept, in the same format so new ones can be added (see `../extending.md`). Stills of these references aren't included in the public download (they're other people's work); the written entries carry the cues. If an `assets/keyframes/` folder is present, stills are there as `<id>.jpg`.

**Status markers:** H = hero only · X = hybrid · bridge = deliberately blends two categories.

**Reminder:** these are other people's concepts. Take the cues; change the colors, imagery, copy and names.
